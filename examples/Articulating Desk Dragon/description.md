# Articulating Desk Dragon

A print-in-place flexi dragon that needs **no supports** and no assembly — it
comes off the bed already articulated.

## Print settings
- **Layer height:** 0.2 mm
- **Material:** PLA
- **Walls:** 3
- **Infill:** 15% gyroid
- **Supports:** none

Print slow on the first layer for clean joints. Enjoy!
