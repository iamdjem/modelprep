# Demo assets

The demo (toggle **Demo** in the app header) populates itself with real, on-topic
3D-print photos (from Wikimedia Commons) and a real, uploadable model file so a
connected user can do a genuine private publish.

## Optional: enable the full print-profile demo

MakerWorld's `.3mf` print-profile path **requires a genuine Bambu-Studio-generated
`.3mf`** — it rejects any other 3mf with *"The 3mf was not generated by Bambu Studio"*.
We can't synthesize one, so by default the demo publishes via the **STL path** (which
always succeeds).

To also demo the **print profile** flow with a real publish, drop a real Bambu Studio
`.3mf` here, named exactly:

```
deploy/public/demo/desk-dragon-bambu.3mf
```

When present, the demo uses it as the print-profile file. When absent, the demo is
STL-only. Nothing else to configure.
