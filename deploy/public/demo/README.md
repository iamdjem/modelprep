# Demo assets

The demo (toggle **Demo** in the app header) loads one internally consistent,
purpose-built certification fixture: the **ModelPrep Calibration Puck**. It contains
two real watertight binary STLs (22 × 3.2 mm and 34 × 4.4 mm), a Bambu
Studio-generated 3MF containing the same 34 mm geometry, and ten model-derived images.

The images are optimized WebP demo renders and do not depend on Wikimedia Commons,
Unsplash, or another runtime image service. They are synthetic demonstration assets,
not photographs of a physical print.

The source-shape mix is deliberate: landscape, portrait, and square assets exercise
platform cropping. The gallery covers the model render, exact dimensions, top/side
views, both STL sizes, flat base, chamfer, Bambu project, file inventory, and an explicit
synthetic-fixture disclosure. All claims in the text and images are derived from the
bundled geometry.

Use these for the UI demo or a private/draft upload-path test. They are renders, not
photographs of a physical print, so `realPhotoConfirmed` is deliberately false. A
MakerWorld path that requires a physical-print photo must fail closed until the user
supplies and confirms one.

## Print-profile fixture

MakerWorld's `.3mf` print-profile path **requires a genuine Bambu-Studio-generated
`.3mf`** — it rejects any other 3mf with *"The 3mf was not generated by Bambu Studio"*.
The repository bundles a genuine Bambu Studio-generated project named:

```
deploy/public/demo/modelprep-calibration-puck-bambu.3mf
```

The 3MF was generated from the same 34 mm STL and can be inspected as a ZIP package.
It is currently an **unsliced project**, not a usable print profile: its embedded
`printer_model` and G-code reference are empty and its `slice_info.config` contains
no plate. ModelPrep therefore keeps it available only as an ordinary raw 3MF and
fails print-profile branches closed. If the file is absent, the demo falls back to
STL-only rather than attaching unrelated or placeholder bytes.
